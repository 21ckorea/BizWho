# 안드로이드 테스트 및 빌드 가이드 (v0.3)

본 문서는 생성된 프로젝트를 실제 안드로이드 기기에서 빌드하고 테스트하기 위한 방법을 안내합니다.

## 1. 사전 준비 (Prerequisites)

1. **Flutter SDK**: PC에 Flutter가 설치되어 있어야 합니다. (안된 경우 [공식 가이드](https://docs.flutter.dev/get-started/install) 참조)
2. **Android 실기기**: 안드로이드 10 (API 29) 이상의 스마트폰과 USB 케이블.
3. **USB 디버깅 활성화**: `설정 > 휴대전화 정보 > 빌드 번호`를 7번 눌러 개발자 모드를 켠 후, `개발자 옵션 > USB 디버깅`을 활성화합니다.

## 2. 빌드 절차

터미널(Terminal)을 열고 프로젝트 루트(`CallerID`) 폴더에서 다음 명령어를 순서대로 입력합니다.

```bash
# 1. 의존성 패키지 다운로드
flutter pub get

# 2. 안드로이드 기기 연결 확인 (연결된 기기 목록에 폰이 나타나야 함)
flutter devices

# 3. 앱 실행 및 설치
flutter run
```

## 3. 테스트 방법 (중요 포인트)

앱이 성공적으로 실행되면 다음 단계를 거쳐 기능을 검증합니다.

### A. 발신자 ID 권한 승인
1. 메인 화면 상단의 **방패 아이콘(Security)**을 클릭합니다.
2. 시스템 팝업에서 **'Caller ID v0.1'**을 기본 앱으로 선택하고 **'기본 앱으로 설정'**을 누릅니다.

### B. 수신 확인 (Call Screening)
1. **연락처에 저장되지 않은** 다른 번호로 이 폰에 전화를 겁니다. (또는 `employee_contacts_sample.csv`에 있는 번호로 테스트)
2. 화면 하단에 **"업무용 전화 확인 중: [번호]"**라는 토스트(Toast) 메시지가 뜨는지 확인합니다.
3. 안드로이드 스튜디오의 `Logcat` 탭에서 `CallerID` 태그로 필터링하여 로그를 확인합니다.

---

## 4. 문제 해결 (Troubleshooting)

- **빌드 에러 (SDK Path)**: 만약 Flutter SDK 경로가 다르다는 에러가 나면, 프로젝트 루트에 `local.properties` 파일을 만들고 `flutter.sdk=/사용자/경로/to/flutter`를 한 줄 추가해 주세요.
- **권한 미승인**: 안드로이드 설정의 `기본 앱 > 발신자 ID 및 스팸 앱` 메뉴에서 수동으로 선택할 수도 있습니다.
