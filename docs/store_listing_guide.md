# 🏪 구글 플레이 콘솔 스토어 등록정보 수정 가이드

스마트폰에서 구글 플레이 스토어를 열었을 때 사용자들에게 보여지는 **앱의 이름, 짧은 설명, 자세한 설명, 스크린샷 이미지** 둥을 변경하는 방법입니다. 소스 코드를 고치는 것이 아니라, 구글 플레이 웹사이트에서 직접 타이핑하여 반영하는 부분입니다.

## 📝 설정 위치

1. 인터넷 창을 열고 [구글 플레이 콘솔 대시보드](https://play.google.com/console) 에 접속하여 앱(비즈후)을 선택합니다.
2. 화면 제일 왼쪽의 길쭉한 회색 메뉴 바를 아래로 쭉 내립니다.
3. **[사용자 늘리기 (Grow)]** 그룹 안에서 **[스토어 등록정보 (Store presence)]** ➡️ **[기본 스토어 등록정보 (Main store listing)]** 를 클릭합니다.

## ✨ 기입할 내용

위 화면에 들어가시면 아래와 같이 원하시는 문구와 이미지로 스토어 화면을 꾸미실 수 있습니다.

- **앱 이름 (App name)**
  - 변경할 이름: `BizWho (비즈후) - 스마트 발신자 식별 앱`
- **짧은 설명 (Short description)**
  - 대략 80자 이내의 한 줄 소개: (예시) `사내 임직원 연락처 데이터를 기반으로 스마트폰에 발신자를 띄워주는 앱`
- **자세한 설명 (Full description)**
  - 보내주신 내용 기입: `사내 임직원 연락처 데이터를 기반으로, 전화 수신 시 발신자의 이름, 직급, 부서 정보를 화면에 즉시 띄워주는 Flutter 기반 안드로이드 애플리케이션입니다.`

## 🎨 아이콘 및 스크린샷

같은 화면의 아래쪽으로 더 내려가시면 스토어용 그래픽 자산을 등록할 수 있습니다.
- **앱 아이콘 (App icon)**: 512x512 픽셀의 `app_icon.png` 이미지를 드래그해서 넣습니다.
- **스크린샷 (Screenshots)**: 스토어에서 보여질 앱 구동 화면 스냅샷을 2~8장 넣습니다.

## 🚀 적용하기
원하시는 내용을 모두 입력하신 후, 우측 하단의 **[저장 (Save)]** 버튼을 누르시면 됩니다. (저장하신 내용이 전 세계 스토어 서버에 반영되어 노출되는 데에는 구글의 내부 처리 시간에 따라 수 시간 정도 걸릴 수 있습니다.)

> [!NOTE]
> 내부 테스트 시 휴대폰 화면 하단에 뜨는 _"You are downloading a test build that has not been verified."_ 라는 영어 경고문은, 앱이 정식 출시(Production) 트랙으로 넘어가는 순간 스토어에서 자동으로 사라집니다!
