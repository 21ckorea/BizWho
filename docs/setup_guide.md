# 📱 비즈후(BizWho) 정식 버전 배포 및 설치 가이드 (v1.7.6 Google Play 공식 버전)

본 가이드는 구글 플레이 스토어(내부 테스트 포함)를 통해 비즈후(BizWho)를 다운로드하고 초기 세팅하는 방법을 안내합니다. 구글 스토어를 통해 설치되므로, 과거 카톡/파일 설치 시 발생하던 각종 보안 차단(오토 블로커 등) 오류가 모두 해결된 무결점 버전입니다.

---

## 📥 배포 정보 (v1.7.6)
- **버전**: `1.7.6` (구글 플레이 정식 스펙, API 35 타겟팅)
- **설치 경로**: 구글 플레이 스토어 (내부 테스트 초대 링크를 통해 스토어에서 직접 설치)
- **특징**: 안드로이드 14+ 호환성 완벽 대응, 백그라운드 렌더링 최적화 적용

---

## ⚙️ 필수 3중 권한 설정 (최초 실행 시 1회 필수)
구글 스토어에서 앱을 다운받아 처음 실행하면, 원활한 오버레이 작동을 위해 아래 3가지 권한을 모두 허용해 주셔야 합니다.

1. **전화 및 통화 기록 (Phone & Call Log)**: **[가장 중요]** 실시간으로 전화번호를 인식하기 위해 반드시 필요합니다. (권한 요청 팝업 시 **'허용'**을 눌러주세요.)
2. **다른 앱 위에 표시 (오버레이)**: 통화 화면 위에 정보창(파란색 카드)을 띄우기 위해 필수입니다.
3. **알림 (Notification)**: 백그라운드에서 매칭 서비스가 안전하게 켜져 있도록 유지하는 데 필요합니다.

---

> [!IMPORTANT]
> **첫 실행 시 주의사항**
> 앱을 새로 설치하고 권한 세팅을 마친 후 처음 실행하면, **"직원 데이터 동기화 완료"** 안내가 나타납니다. 이 메시지가 뜬 이후에 전화를 테스트해야 정확하게 이름이 표시됩니다!

> [!TIP]
> **이제 오토 블로커 해제는 필요 없습니다! 🎉**
> 과거 버전(APK 직접 설치)에서는 삼성 폰의 '보안 위험 자동 차단(Auto Blocker)' 기능이 오버레이를 강제로 먹통 만들었으나, 이제 **구글 플레이 스토어를 통해 공식 인증을 받고 설치**되므로 까다로운 삼성의 보안 우회 설정을 더 이상 하실 필요가 없습니다.

## 🔍 정보가 뜨지 않을 때 자가 진단 가이드

전화가 왔을 때 파란색 발신 정보 카드가 나타나지 않고, 화면 하단에 검은색 바(토스트)만 나타난다면 아래 조치법을 확인하세요:

1. **"비즈후: 번호 수신 불가"** 🚫
   - **원인**: 시스템이 전화번호를 숨김 처리했거나, 통화 기록 권한이 없습니다.
   - **조치**: 앱 정보 -> 권한 -> **'통화 기록'** 권한 및 **'전화'** 권한을 '허용'으로 다시 확인해 주세요.

2. **"비즈후: 시스템 수신 보고됨! (매칭 실패: 010...)"** 🔍
   - **원인**: 번호는 성공적으로 인식했지만, 앱 내부 DB(CSV 파일)에 해당 번호의 직원 정보가 없습니다.
   - **조치**: 발신 번호가 실제 직원 DB(`employee_contacts.csv`)에 등록되어 있는지 확인하세요.

3. **"② 화면 소환 시도 중..."에서 멈추는 경우** ⚠️
   - **원인**: 시스템이 화면 그리기 권한을 뺏어갔을 가능성이 큽니다.
   - **조치**: 스마트폰 설정 -> 애플리케이션 -> 비즈후 -> **'다른 앱 위에 표시'** 권한이 켜져 있는지 확인하세요.

4. **아무런 메시지도 나타나지 않음** 😶
   - **원인**: 앱이 구글의 배터리 절전 모드에 의해 완전히 잠들었거나 백그라운드 서비스가 종료되었습니다.
   - **조치**: 앱 정보 -> 배터리 -> **'제한 없음(최적화 예외)'** 설정으로 변경해 주세요.
